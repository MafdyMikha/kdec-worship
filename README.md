# KDEC Worship Platform

Full-featured worship team planning platform for Kasr El Doubara Evangelical Church, inspired by Planning Center.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Features

- **Dashboard** – Overview, upcoming services, top songs, team snapshot
- **Services** – Create/manage services, setlist builder (drag-to-reorder), team assignment
- **Songs** – Song library (English + Arabic), key/BPM/CCLI, song structure
- **People** – Team directory, roles, availability, status
- **Schedule** – Monthly calendar + list view
- **Reports** – Usage analytics, top songs, team stats
- **Announcements** – Team-wide posts with priority levels
- **Settings** – Org settings, data export/import

## Stack

React + Vite · Tailwind CSS · React Router · date-fns · lucide-react · localStorage
